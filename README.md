# Employee-Data--Data-Analysis
Taking an Employee Data file in python and cleaning its data and doing EDA (Exploaratory Data Analysis) on it and Plotting the Data

Packages used are Pandas and Matplotlib

Steps followed in the program :
  i) The csv file is inputted in the program through the variable "data"
  ii) The data is then cleaned [missing values are replaced with mean values (age), two columns containing the data that needs to be accessed different is split into two (department and      region, date format is fixed)
  iii) Then analysis is done on the cleaned data and some answers are solved with its help
  iv) Then that data is plotted with the help of matplotlib
